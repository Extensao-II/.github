# Task 1: Sugestão de Temas (Professores e Externos) (UC6, UC7)
​Criar formulário de sugestão de temas (título, descrição, áreas, áreas correlatas).

Adicionar aceite obrigatório de termos de uso e não-propriedade.

​Diferenciar fluxo: temas de professores (podem ser auto-vinculados).

# Task 2: Cadastro de Administradores de Curso/Colegiados (UC2)

Administrador central deve poder cadastrar novos colegiados vinculados a cursos.

# Task 3: Gerenciamento de Convites para Professores (UC3)

Colegiado deve poder cadastrar listas de e-mails de professores autorizados a usar o sistema.

# Task 4: Auto-cadastro de Professores (UC4)

Permitir o primeiro acesso do professor usando um código enviado para o e-mail pré-cadastrado.

Incluir formulário para vincular Lattes, preferências de contato, senha e áreas de atuação.

# Task 5: Edição de Perfil do Professor (UC5)

Criar tela para o professor atualizar seus dados (Lattes, áreas, senha e contatos).
